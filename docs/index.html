01 / Method

Learn from language-model loss.

Local KV reconstruction error is only a proxy for generation quality: a cache perturbation passes through attention and the remaining network before it changes a prediction. Beyond learns representation levels R and ordered decision thresholds T directly from next-token negative log-likelihood, while keeping the backbone weights frozen.

For each 32-value group, normalize with its minimum and scale, assign each value to one of 16 learned levels using 15 interior thresholds, then rescale for attention. Training and inference share the same hard bin assignment.

Hard forward, loss-driven updates

Identity straight-through input gradients and boundary-localized threshold pseudo-gradients enable learning. Only the quantizer parameters are updated.

What fits in the cache

Each group stores 128 code bits plus 32 min/scale metadata bits: 5.0 effective bits per scalar, or 3.2× payload compression relative to 16-bit KV, before page padding.

Payload compression is not a claim of 3.2× lower total GPU memory: model weights, workspaces, and cache-allocation overhead are separate.

02 / Quality

Beyond the full-precision baseline.

Quantizer-only training lowers held-out Pile perplexity on all three tested instruction-tuned models. On LongBench, Beyond achieves the highest Avg21 among Native, KV-FP8, TurboQuant, and Beyond for each model.

03 / Packed execution

From compressed KV
to faster decoding.

A fused CuTe decode kernel reads packed codes and combines level lookup, affine rescaling, attention scoring, online softmax, and value accumulation. The vLLM integration measures how this kernel translates into end-to-end serving.

1.50× peak kernel speedup

Versus FlashAttention-4 on one NVIDIA B300, using Llama-3.1-8B-Instruct geometry. The poster shows all 16 measured context/batch pairs.

1.17× peak serving throughput

Versus the FA4 vLLM path at batch 1536. Tested batch capacity increases from 1582 to at least 4500: at least 2.84×.

Two measurements, two scopes

Kernel-only: batches 1 and 16, 1K–128K contexts, 50 warmups, and 500 CUDA-graph replays. Speedup is FA4 latency divided by Beyond latency.

End-to-end: Llama-3.1-8B-Instruct in BF16 on one B300; the official vLLM throughput benchmark with cold 1024-token prompts plus 128 generated tokens, an 8192-token scheduling budget, prefix caching off, and GPU-memory fraction 0.90.

Capacity: the first tested KV-capacity failures occur at 1583 for FA4 and 4800 for Beyond. Batch 4500 is a verified working point, not an exact maximum for Beyond.

See both performance plots in the final poster

Evidence boundaries. Quality evaluation uses training-equivalent fake quantize/dequantize (fake-QDQ) with a floating-point cache. Real cache compression and serving measurements use the packed backend. These are separate experiments, and kernel speedup is not end-to-end throughput gain.
