Learn the quantizer. Freeze the model. Decode packed KV.

Compression need not trade away model quality. Beyond learns non-uniform KV-cache quantizers directly from next-token prediction loss. Across three tested instruction-tuned models, 4-bit caches lower held-out perplexity and improve long-context benchmark averages. A separate packed-cache implementation brings compression to vLLM serving.

01 / Method

Learn the cache,
not the model.

Local KV reconstruction error is only a proxy for generation quality: a cache perturbation passes through attention and the remaining network before it changes a prediction. Beyond learns representation levels R and decision thresholds T directly from next-token negative log-likelihood (NLL), while keeping the backbone weights frozen.

01 / Representation

One learned table for each KV group

Each layer × K/V projection × KV head × 32-dimensional group has its own scalar quantizer, shared across sequence positions. Keys are quantized after RoPE; values after projection. The group minimum m and range s normalize each scalar z to [0, 1].

x = clip((z − m) / (s + ε), 0, 1)

Here m = min(z) and s = max(z) − min(z) within the current group. These statistics come from the activations; the learned parameters are the levels and thresholds.

02 / Hard assignment

Learn where the bins are—and what they return

Fifteen interior thresholds select one of sixteen representation levels. The endpoints stay fixed at t0 = 0 and t16 = 1. Unlike a fixed uniform grid, thresholds and reconstruction levels can adapt independently.

Q(x; R, T) = rk for x ∈ Bk(T)
ẑ = m + s · Q(x; R, T)

Bk = [tk, tk+1); the last bin also includes 1. Initialization uses rk = k / 15 and midpoint thresholds. Every training forward pass uses the same hard assignment as inference.

03 / Learning objective

Optimize the prediction, not a reconstruction proxy

Run the frozen model with quantized K/V and minimize next-token NLL. Only R and T receive optimizer updates; the backbone θ remains fixed.

minR,T∑X∈𝒳∑t−logpθ(xt+1|x≤t;QR,T)

𝒳 is the training sequence stream; t runs over next-token prediction positions.

04 / Backward pass

Hard forward. Explicit surrogate gradients.

A hard bin assignment is not differentiable at its boundaries. Beyond uses an identity straight-through estimator for the input, accumulates gradients for each selected level, and updates thresholds from nearby boundary signals.

The paper uses half-wave rectification: positive left-side signals and negative right-side signals supply opposing candidate directions for a threshold update. Thresholds are projected back to an ordered feasible set after each optimizer step.

No soft assignments, temperature, or annealing schedule is introduced. These are pseudo-gradients, not exact derivatives of the hard threshold objective or a guarantee that every update reduces NLL.

05 / Packed deployment

Keep codes in memory; reconstruct inside attention

The cache writer stores a 4-bit code per scalar and FP16 minimum/scale statistics per group. Learned thresholds assign new values to codes; learned levels reconstruct them during attention. A fused decode kernel consumes this packed representation directly.

(32 × 4 + 2 × 16) / 32 = 5 bits/scalar
16 / 5 = 3.2× KV payload compression

This counts per-group metadata, before page padding. Persistent quantizer tables, model weights, and workspaces are separate; it is not a 3.2× reduction in total GPU memory.

The backward rules, precisely

Let g(x) = ∂L/∂x̂ be the downstream gradient at the normalized quantizer output. The input STE uses ∂L/∂x ≈ g(x). Each level receives the sum of gradients from the samples assigned to its bin:

∂L/∂rk = ∑x ∈ Bk g(x)

For threshold tk, define Δrk = rk − rk−1. With εbw = 0.009, aggregate minibatch gradients in the left window [tk − εbw, tk) and right window [tk, tk + εbw]:

GL = −Δrk ∑x ∈ WL g(x),   GR = −Δrk ∑x ∈ WR g(x)
ĝtk = max(GL, 0) + min(GR, 0)

Under gradient descent, the positive left component moves the threshold left and the negative right component moves it right. These are directional, boundary-localized surrogate signals. Level and threshold gradients are explicitly defined in the custom backward pass; an input-only stop-gradient expression would not learn R and T by itself.

This section describes the paper's half-wave rule. See the usage guide for the public training entry point.

Why can quantization lower the loss?

The direction of a perturbation matters, not just its size. For downstream loss Ψ, a local expansion around cached representations z separates first-order alignment from a second-order contribution:

E[Ψ(z + δ)] − Ψ(z)
= ⟨∇Ψ(z), E[δ]⟩ + ½ Tr(H E[δδ⊤]) + ρ

Under a β-Lipschitz Hessian along the relevant segments, |ρ| ≤ (β/6) E‖δ‖³. A loss-aligned perturbation can therefore help even when its local reconstruction error is nonzero. This motivates learning the quantizer from NLL instead of assuming that the smallest reconstruction error is always best.

The true downstream Hessian H may be indefinite; the second-order term is not necessarily a positive penalty. This local analysis is not a guarantee of improvement for every input or task, and does not establish that learned quantization always increases attention entropy. Formal assumptions and proofs are in the paper and appendix.

Training setup and parameter footprint
Optimizer
Adam, 7 × 10−4, cosine decay; at most 500 optimizer steps.
Data / batch
The Pile; 8192-token sequences; global effective batch size 32; seed 42.
Checkpoint selection
150 validation chunks, full validation every 10 updates, patience 3; select the best checkpoint. Evaluation uses 150 disjoint chunks.

Each table has 16 levels and 15 interior thresholds. For L layers, Hkv KV heads, and head dimension dh, there are 2LHkvdh/32 tables, shared across tokens.

The evaluated models use 47,616–79,360 learned scalar parameters. FP32 master parameters are used for training; deployed R/T tables use FP16. Their persistent storage is 93–155 KiB, separate from per-token cache payload.

Non-uniform tables are supported independently for K and V; learning does not require every table to become non-uniform. The retained Ministral K tables remain on their initialized uniform grid.

03 / Packed execution

From compressed KV
to faster decoding.

A fused CuTe decode kernel reads packed codes and combines level lookup, affine rescaling, attention scoring, online softmax, and value accumulation. The vLLM integration measures how this kernel translates into end-to-end serving.

Prefill keeps the standard dense-attention path with model-dtype quantize/dequantize K/V, while the cache writer stores persistent packed codes. During single-token decode, code lookup and affine rescaling occur in registers; reconstructed values feed tensor-core attention tiles without materializing a dense KV cache in HBM.

1.50× peak kernel speedup

Versus FlashAttention-4 on one NVIDIA B300, using Llama-3.1-8B-Instruct geometry. The poster shows all 16 measured context/batch pairs.

1.17× peak serving throughput

Versus the FA4 vLLM path at batch 1536. Tested batch capacity increases from 1582 to at least 4500: at least 2.84×.

Two measurements, two scopes

Kernel-only: batches 1 and 16, 1K–128K contexts, 50 warmups, and 500 CUDA-graph replays. Speedup is FA4 latency divided by Beyond latency.

End-to-end: Llama-3.1-8B-Instruct in BF16 on one B300; the official vLLM throughput benchmark with cold 1024-token prompts plus 128 generated tokens, an 8192-token scheduling budget, prefix caching off, and GPU-memory fraction 0.90.

Capacity: the first tested KV-capacity failures occur at 1583 for FA4 and 4800 for Beyond. Batch 4500 is a verified working point, not an exact maximum for Beyond.

See both performance plots in the final poster

Evidence boundaries. Quality evaluation uses training-equivalent fake quantize/dequantize (fake-QDQ) with a floating-point cache. Real cache compression and serving measurements use the packed backend. These are separate experiments, and kernel speedup is not end-to-end throughput gain.
